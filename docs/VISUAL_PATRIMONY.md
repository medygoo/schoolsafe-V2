# Contrat de patrimoine visuel SchoolSafe

Ces elements restent presents dans SchoolSafe V2:

- l'ecran d'accueil bleu;
- le logo SchoolSafe et les lignes multicolores;
- les petites particules multicolores qui montent;
- les textes historiques de l'ecran d'accueil, mot pour mot;
- l'ecran de portraits d'enfants alignes, sans video;
- l'animation avant/arriere calibree sur les visages;
- la rotation des photographies derriere l'ecran de connexion;
- le cube 3D anime qui ouvre le menu dans les espaces des profils;
- le slogan « Chaque enfant protege, chaque parent informe ».

Le cube conserve son mouvement, son role de bouton de menu et sa place dans la
barre superieure. Une maquette de profil ne peut pas le remplacer par une icone
statique.

Le formulaire de connexion conserve un fond transparent afin de laisser la
photographie visible. Les acces par e-mail et par telephone sont separes: un
utilisateur choisit un mode et ne saisit jamais les deux identifiants.
