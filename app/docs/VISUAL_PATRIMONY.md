# Contrat de patrimoine visuel SchoolSafe

Ces éléments appartiennent à l’identité fonctionnelle de SchoolSafe et restent
présents dans la V2:

- l’écran d’accueil bleu;
- le logo SchoolSafe;
- les lignes multicolores;
- les textes historiques de l’écran d’accueil, mot pour mot;
- l’introduction animée avec les jeunes filles;
- la rotation des photographies sur l’écran de connexion;
- le cube 3D animé qui ouvre le menu dans les espaces des profils;
- le slogan « Chaque enfant protégé, chaque parent informé ».

Le cube sera intégré au shell applicatif partagé par les profils lors de la phase
des tableaux de bord. Il conservera son mouvement, son rôle de bouton de menu et
sa place dans la barre supérieure. Une maquette de profil ne peut pas le remplacer
par une icône statique.
